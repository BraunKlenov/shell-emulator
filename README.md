# Эмулятор оболочки ОС с виртуальной файловой системой

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант 17.

## 1. Общее описание

Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом (GUI).
Пользователь вводит команды в окне, похожем на терминал, а эмулятор
выводит результат их выполнения. Работа ведётся по этапам; каждый этап
отражён отдельным коммитом в истории репозитория.

Текущее состояние: **этап 1 — REPL** (минимальный прототип).

| Этап | Содержание                      | Статус    |
|------|---------------------------------|-----------|
| 1    | REPL, парсер, `ls`/`cd`/`exit`  | выполнен  |
| 2    | Конфигурация (параметры, скрипт)| запланирован |
| 3    | Виртуальная файловая система    | запланирован |
| 4    | `ls`, `cd`, `date`, `echo`      | запланирован |
| 5    | `touch`, `chmod`                | запланирован |

Язык реализации: Python 3.8+. Внешние зависимости не нужны: GUI написан
на стандартной библиотеке `tkinter`.

## 2. Описание функций и настроек

### Окно

* Заголовок окна содержит имя VFS: `Shell emulator - VFS: vfs`.
* Приглашение имеет вид `пользователь@vfs:/$ `, где `пользователь` —
  имя пользователя реальной ОС.
* Ввод возможен только в последней строке; приглашение защищено
  от редактирования.
* Клавиши: `Enter` — выполнить команду, `Up`/`Down` — история команд,
  `Home` — начало ввода (после приглашения).
* Ошибки выводятся красным цветом.

### Парсер

Строка разбирается на слова по правилам, близким к POSIX-оболочкам:

| Конструкция        | Поведение                                          |
|--------------------|----------------------------------------------------|
| `$NAME`, `${NAME}` | подстановка переменной окружения **реальной** ОС   |
| неизвестная `$X`   | раскрывается в пустую строку                       |
| `'...'`            | одинарные кавычки: текст берётся как есть          |
| `"..."`            | двойные кавычки: переменные раскрываются           |
| `\x`               | экранирование символа (`\$` даёт обычный `$`)      |
| `''`               | пустой аргумент                                    |

Переменная `HOME` определяется автоматически, если ОС её не задаёт
(например, в Windows).

Ошибки разбора: незакрытая кавычка, обрывающий строку `\`,
некорректная подстановка вида `${a b}` или `${HOME`.

### Команды

| Команда        | Описание (этап 1)                                        |
|----------------|----------------------------------------------------------|
| `ls [арг...]`  | заглушка: выводит своё имя и аргументы                   |
| `cd [арг...]`  | заглушка: выводит своё имя и аргументы                   |
| `exit [код]`   | закрывает окно; необязательный числовой код возврата     |

Обработка ошибок:

* неизвестная команда: `shell: foo: command not found`;
* ошибка разбора: `shell: parse error: ...`;
* `exit abc`: `exit: abc: numeric argument required`;
* `exit 1 2`: `exit: too many arguments`.

Настроек командной строки на этом этапе нет (они появятся на этапе 2).

## 3. Сборка и запуск тестов

Сборка не требуется. Нужен Python 3.8+ с модулем `tkinter`
(в Windows и macOS он входит в установщик; в Debian/Ubuntu:
`sudo apt install python3-tk`).

Запуск приложения:

```sh
./run.sh          # Linux / macOS
run.bat           # Windows
make run          # любая ОС с make
```

Запуск тестов (тесты окна автоматически пропускаются, если нет дисплея
или `tkinter`):

```sh
make test
# или без make (Linux / macOS):
PYTHONPATH=src python3 -m unittest discover -s tests -v
# или без make (Windows, cmd):
set PYTHONPATH=src && python -m unittest discover -s tests -v
```

Структура репозитория:

```
src/vfs_shell/    исходный код (parser, commands, shell, gui)
tests/            модульные тесты
run.sh, run.bat   запуск приложения
Makefile          цели run и test
```

## 4. Примеры использования

Пример сеанса (в Linux; `$HOME` берётся из реальной ОС):

```text
student@vfs:/$ ls
command: ls, arguments: []
student@vfs:/$ ls -l /tmp "my dir"
command: ls, arguments: ['-l', '/tmp', 'my dir']
student@vfs:/$ cd $HOME
command: cd, arguments: ['/home/student']
student@vfs:/$ cd "${HOME}/docs"
command: cd, arguments: ['/home/student/docs']
student@vfs:/$ cd '$HOME'
command: cd, arguments: ['$HOME']
student@vfs:/$ cd $NO_SUCH_VARIABLE
command: cd, arguments: []
student@vfs:/$ foo
shell: foo: command not found
student@vfs:/$ ls 'abc
shell: parse error: unterminated single quote
student@vfs:/$ exit abc
exit: abc: numeric argument required
student@vfs:/$ exit
```

Последняя команда закрывает окно.
